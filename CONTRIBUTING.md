# Участие в проекте

Это решение задания для AQA-стажёра. В сдаваемой версии сохранены два исходных сценария и один дополнительный тест, как требует условие.

## Подготовка

Установите Node.js из `.nvmrc`, затем выполните:

```shell
npm ci
npm run check
npx playwright install chromium
npm test
```

Описание сценариев, запуска через Docker и известных ограничений есть в [README](README.md). После локального запуска отчёт открывается автоматически; сервер можно остановить через `Ctrl+C`.

## Изменения

1. Создайте отдельную ветку для исправления.
2. Используйте локаторы по тестовым атрибутам, роли или видимому имени, когда они доступны. Обоснуйте зависимость от CSS в описании изменения.
3. Используйте ожидания Playwright и проверки `expect`; не подменяйте их фиксированными паузами.
4. Выполните `npm run check` и `npm test` и укажите фактический результат в Pull Request. Для исправления форматирования используйте `npm run format`. Если произошла ошибка навигации, приложите её текст и JSON-вложение диагностики; отметьте, дошёл ли тест до виджета.
5. Выполните `git diff --check`. При изменении зависимостей обновите и `package-lock.json`.
6. При обновлении Playwright сохраняйте одинаковые версии в `package.json` и `Dockerfile`, обновите версии в README и проверьте запуск в Docker. Dependabot предлагает изменения через PR; их нужно проверить перед слиянием.

Отчёты и `node_modules/` не включаются в коммит. Перед публикацией логов или trace проверьте, что в них нет токенов, cookie и персональных данных.

## Сообщения об ошибках

Для ошибки тестов используйте [шаблон Issue](https://github.com/huksleva/aqa-intern-challenge/issues/new/choose): укажите команду запуска, окружение, шаги, ожидаемый и фактический результат. Вопросы по запуску можно обсуждать в [Discussions](https://github.com/huksleva/aqa-intern-challenge/discussions).

Уязвимости репозитория сообщайте приватно по инструкции в [SECURITY.md](SECURITY.md). Правила общения — в [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
