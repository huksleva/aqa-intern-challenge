# Политика безопасности

## Область поддержки

Исправления безопасности принимаются для текущей версии в ветке `master`. Проект содержит автотесты и их зависимости; он не является сервисом Учи.ру.

## Сообщить об уязвимости

Для проблемы безопасности этого репозитория используйте приватную форму GitHub: **Security → Report a vulnerability**.

[Отправить приватное сообщение](https://github.com/huksleva/aqa-intern-challenge/security/advisories/new)

Укажите затронутый файл или зависимость, версию/коммит, способ воспроизведения и возможное влияние. Не публикуйте секреты, токены или персональные данные в открытых Issues. Срок ответа заранее не гарантируется.

Уязвимости самого сайта `uchi.ru` следует сообщать его владельцам через их официальные каналы. Здесь рассматриваются только проблемы автотестов и настройки этого репозитория.

## Проверка зависимостей

```shell
npm audit
```

Наличие lock-файла позволяет повторить установку, но не заменяет проверку новых уязвимостей. HTML-отчёт и trace могут содержать данные браузерной сессии — просматривайте их перед передачей другим людям.
